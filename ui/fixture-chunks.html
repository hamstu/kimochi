How to use this with cloud OCR

Each sentence has a small gap inside one or two words (食べ|ました, 走っ|ている, 美し|かった, 日本|語, 勉強|します, 読み|たい, and in the vertical column 食べ|ます, 話し|かけた, 東|京, 行き|ました). A reader sees one word; Google Vision does not know Japanese word boundaries and returns the two halves as separate chunks.

  1. Set the OCR engine to Google Cloud Vision and turn text grouping off (ungrouped words mode: one box per OCR chunk).
  2. Choose a source that covers this window (a display or region; Kimochi's own windows are not offered in the window picker), or open ui/fixture-chunks.html in a browser and pick that window.
  3. Scan, then hover the first half of a split word (食べ) with the lookup modifier. The popup should show the whole word (食べる for 食べました), anchored on the hovered box, not shifted towards the following chunk.
  4. If OCR still reads a split word as one chunk, widen the gap with the slider. If it starts reading the halves as separate lines, narrow it.
  5. The vertical column checks reading order: the lookahead follows columns right to left, each top to bottom.

Local MeikiOCR returns whole lines, so it should look the same before and after.
