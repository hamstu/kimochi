---
title: Files and data
description: Where Kimochi keeps its settings, Log, dictionaries and downloads, and what each holds.
---


Kimochi keeps everything on your computer, in its data folder, under the app id `dev.kimochi.app`:

| System | Data folder |
| --- | --- |
| macOS | `~/Library/Application Support/dev.kimochi.app/` |
| Linux | `~/.local/share/dev.kimochi.app/`, plus `~/.config/dev.kimochi.app/` and `~/.cache/dev.kimochi.app/` |
| Windows | `%APPDATA%\dev.kimochi.app\` and `%LOCALAPPDATA%\dev.kimochi.app\` |

## What's in it

| What | Where |
| --- | --- |
| Settings (including your DeepL key and window positions) | `settings.json` |
| The Log, sessions, stats and Notebook (no account) | The data folder itself: `sessions.json`, `sessions/`, `stats.json` and friends |
| The same, per signed-in account | `profiles/<server>-<account>/` |
| Downloaded dictionary engines | `extensions/<engine>/<version>/` |
| Downloaded OCR models (and the speech model) | `models/<engine>/` |
| Screenshots of the newest scans | `screenshots/` (on Windows, under `%LOCALAPPDATA%`, like the models) |
| The sync log | `sync-log.jsonl` |
| Dictionaries you import | The app's web storage (IndexedDB), managed in the engine's settings |

Captured images are held in memory while Kimochi reads them. What is saved is a screenshot of each
of the newest scans (50 by default; see [Screenshot](/lookups/anki/#screenshot)) and the images you add
to the Notebook. Deleting the data folder removes all of it.

Imported dictionaries live in the app's web storage, outside the data folder: on macOS in
`~/Library/WebKit/dev.kimochi.app/`, on Windows inside `%LOCALAPPDATA%\dev.kimochi.app\` (the
`EBWebView` folder), and on Linux alongside the data folder. To keep a copy, use Yomitan's own
**Backup** (below).

## Backing up

- **With Kimochi Cloud**, Sync keeps a copy on the server, and **Settings → Account → Export your data**
  saves it as a ZIP. See [Sync and backup](/cloud/sync/).
- **Without one**, copy the data folder while Kimochi is closed.
- Yomitan dictionaries and settings can be exported from Yomitan's own settings (its **Backup**
  section).
