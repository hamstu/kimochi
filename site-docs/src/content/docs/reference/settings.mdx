Open Settings from the sidebar's **Settings** row, with <kbd>⌘,</kbd> / <kbd>Ctrl+,</kbd>,
or from the tray icon's menu (**Settings…**). On a Mac it is also in the Kimochi menu. It has
eleven pages.

<Tabs>
  <TabItem label="General">
    How Kimochi looks on this computer.

    | Setting | Default | Notes |
    | --- | --- | --- |
    | **Theme** | System | System, Light or Dark. |
    | **Interface size** | Medium | Small, Medium, Large or XL. Scales text, spacing and controls in every window; the Log keeps its own text size. |
    | **Sound effects** | On | Every sound on or off. The speaker in each title bar toggles them too. |
    | **Scan sounds** | On | Under Sound effects: a sound when a scan starts, adds lines to the Log or fails. |
    | **Click sounds** | On | Under Sound effects: a click for buttons, switches and menus, and a whoosh when the sidebar shows or hides. |
    | **Volume** | 50% | Under Sound effects: how loud every sound effect plays. |
    | **Debug overlay** | Off | Marks the scanned text boxes over the source and opens the Diagnostics window. |
    | **GNOME overlay** | — | Linux, GNOME only. See [Install on Linux](/install/linux/#the-overlay-on-wayland). |
    | **Kimochi in Steam** | — | Linux with Steam only. See [Steam Deck](/install/steam-deck/#adding-to-steam-later). |
    | **Welcome guide** | — | **Open** runs the [welcome guide](/welcome-guide/) again. |

    <Screenshot id="settings-general" alt="Settings, General page." width={760} />
  </TabItem>
  <TabItem label="Sources">
    Where the Log's lines come from. See [Sources and crop](/reading/sources/) and
    [Texthookers and clipboard](/reading/texthookers/).

    | Setting | Default | Notes |
    | --- | --- | --- |
    | **Input** | Screen | Screen, Quick Shot, Clipboard or WebSocket. |
    | ↳ **Poll interval** (Clipboard) | 200 ms | 100 ms, 200 ms, 500 ms or 1 s. |
    | ↳ **WebSocket URL** | `ws://localhost:6677` | |
    | **Auto switch sessions by window name** | On | Each window you read gets its own session. |
    | **macOS permissions** | — | Screen Recording (reads the window or screen you choose) and Accessibility (brings your source's window to the front): Allowed, or a button to allow it. |
    | **Copy scans to clipboard** | Off | |
    | **Send scans over WebSocket** | Off | Hosts a WebSocket server at its **WebSocket URL** (`ws://localhost:6677`). |
  </TabItem>
  <TabItem label="OCR & Overlay">
    Which engine reads the screen, and what is drawn over your source. See
    [OCR engines](/reading/ocr-engines/), [The overlay](/reading/overlay/) and
    [Auto OCR](/reading/auto-ocr/).

    | Setting | Default |
    | --- | --- |
    | **Engine** | Google Lens |
    | **Overlay mode** | Off |
    | **Group text into regions** | Off |
    | **Filter out furigana and small text** | On, strength Balanced |
    | **Scan after a button press** | Off; **Scan delay** 500 ms, **Gamepad trigger** none |
    | **Auto OCR** | Off; the same switch as the main window's |
    | ↳ **Advanced options**: **Adaptive polling** | On |
    | ↳ **Settle after** | 2 readings |
    | ↳ **Give up waiting after** | 4 seconds |
    | ↳ **Minimum time between requests** | 1.2 seconds |
    | ↳ **Base poll interval** | 500 ms |
  </TabItem>
  <TabItem label="Log & Sessions">
    How the transcript reads, which lines it keeps, and your sessions. See [The Log](/log/the-log/)
    and [Sessions](/log/sessions/).

    | Setting | Default | Notes |
    | --- | --- | --- |
    | **Text size** | 14 px | 12–48 px; also A− and A+ in the Log's footer. |
    | **Read-aloud voice** / **Voice model** | Eleven v3 | With Kimochi Cloud. |
    | **Japanese only** | Off | |
    | **Skip repeats** | 1 | Drop a line that matches any of the last N lines (1–20). |
    | **Merge streamed lines** | Off | Characters to compare: 4. |
    | **Keep at most** | 5000 | Lines per session. |
    | **Text replacements** | None | Pattern rules applied to incoming lines. |
    | **Pause when idle for** | 60 s | The reading timer (10–600 s). |
    | **Sessions** | — | Every session: drag to reorder, click a name to rename, switch, delete, or add one. |
  </TabItem>
  <TabItem label="Dictionary">
    The pop-up that shows definitions. See [Dictionaries](/lookups/dictionaries/).

    | Setting | Default |
    | --- | --- |
    | **Engine** | Built-in Yomitan |
    | **Open … settings** | The engine's own settings page (Yomitan, Hachidori, 10ten). |
    | **API address** (Yomitan API) | `http://127.0.0.1:19633` |
    | **Pop-up size** (Yomitan API) | 480 × 360 |
    | **Fetch word audio** / **Play on lookup** / **Volume** (Yomitan API) | On / On / 90% |
    | **Anki cards** | A link to Settings → Anki. |
  </TabItem>
  <TabItem label="Anki">
    Cards through AnkiConnect, whatever the dictionary engine. See [Anki](/lookups/anki/).

    | Setting | Default |
    | --- | --- |
    | **AnkiConnect** tab: status, **Address** | `http://127.0.0.1:8765` |
    | ↳ **API key** | Empty; stored locally, never synced |
    | **Mining** tab: **Open … Anki settings** (Built-in Yomitan, Hachidori) | The engine's own Anki settings, AnkiConnect address and key included |
    | ↳ **Enable Mining** / **Deck** / **Note type** (Yomitan API) | Off / — / — |
    | ↳ **Detect from Anki** / **Import from Yomitan** / **Field mapping** (Yomitan API) | — |
    | **Card enhancement** tab: **Enhance with sentence audio** | Off (turning it on downloads the speech model) |
    | ↳ **Audio field** | `SentenceAudio`, found in Anki when turned on |
    | ↳ **Advanced**: **Start offset** / **End offset** / **Seconds kept** / **Clips kept** | 0 ms / 0 ms / 30 / 15 |
    | **Card enhancement** tab: **Enhance with screenshot** | On |
    | ↳ **Picture field** | `Picture`, found in Anki when turned on |
    | ↳ **Screenshots kept** | 50 |
    | **Card enhancement** tab: **Add tags** / **Tags** | On / `kimochi, {{session-name}}` |

    10ten adds no cards, and an engine that isn't downloaded yet only offers **Go to Dictionary**.
  </TabItem>
  <TabItem label="Translation & AI">
    Help with a line you can't read yet. See [Translation and AI](/lookups/translation-and-ai/).

    | Setting | Default |
    | --- | --- |
    | **Translate with** | **Kimochi cloud** (with Kimochi Cloud) or **Your DeepL key**; Kimochi cloud if you have Kimochi Cloud, otherwise your DeepL key |
    | **DeepL API key** (Your DeepL key) | Empty; stored locally, never synced |
    | **Explain with AI → Configure…** | Codex CLI, its default model, the default prompt |
  </TabItem>
  <TabItem label="Shortcuts & Controls">
    Keyboard shortcuts and a game controller. See [Keyboard shortcuts](/reference/shortcuts/) and
    [Controller](/controller/).

    | Setting | Default |
    | --- | --- |
    | **Scan** | <kbd>⇧⌘8</kbd> / <kbd>Ctrl+Shift+8</kbd>, no gamepad button |
    | **Controller menu** | <kbd>⇧⌘Space</kbd> / <kbd>Ctrl+Shift+Space</kbd>, LS + RS |
    | **Enable gamepad support** | On |
    | **Controller menu**: **Select** / **Back** | A / B |
    | **Reading**: **Word or character** / **Play audio** / **Previous definition** / **Next definition** / **Show all controls** | Y / X / LB / RB / View |
    | **Connected gamepads** / **Button test** | — |

    Two actions on the same button are pointed out.
  </TabItem>
  <TabItem label="Game Mode">
    How Read along shows the dictionary. See [Controller](/controller/).

    | Setting | Default | Notes |
    | --- | --- | --- |
    | **Dictionary in Read along** | Pop-up | **Pop-up** beside the word, or **Full screen**: the scanned text across the top with the dictionary filling the space below, with any dictionary. |

    The buttons Read along uses are in **Shortcuts & Controls**.
  </TabItem>
  <TabItem label="Account">
    Optional. Everything else in Kimochi works without one. See [Accounts and plans](/cloud/) and
    [Sync and backup](/cloud/sync/).
  </TabItem>
  <TabItem label="About">
    Your version and its updates, links and credits. **About Kimochi** in the macOS menu and in the
    tray menu opens it.

    | Section | What it has |
    | --- | --- |
    | **Updates** | Your version, when it last checked, **What's new** and **Check for updates** (or the update's download and **Restart to update**). See [Updates](/install/#updates). |
    | **Links** | Website, Documentation, Discord and Source code. |
    | **Acknowledgements** | The open-source projects Kimochi is built on, with their licences. |
  </TabItem>
</Tabs>
