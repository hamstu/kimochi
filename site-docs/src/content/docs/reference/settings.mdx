Open Settings with <kbd>⌘,</kbd> / <kbd>Ctrl+,</kbd> or **Settings** in the menu of the sidebar's account button.

<Tabs>
  <TabItem label="Account">
    Settings, sessions and your notebook are saved per account. See [Accounts and plans](/cloud/)
    and [Sync and backup](/cloud/sync/).

    | Section | What it has |
    | --- | --- |
    | **Accounts** | Every account on this computer, with **Switch** and **Active**. **Add account** adds a **Local account** (kept on this computer, with a name and picture you choose) or a **Cloud subscription** (sign in to Kimochi Cloud). Each account's ⋯ menu has **Edit…** for a local one, or **View details online** and **Sign out** for a Kimochi Cloud one, and removing it. **Default** is the account Kimochi starts with. |
    | **Yomitan profile** | With Built-in Yomitan, under the account in use: the Yomitan profile it looks words up with, and **Manage**. See [A dictionary profile for each account](/language/support/#a-dictionary-profile-for-each-account). |
  </TabItem>
  <TabItem label="General">
    How Kimochi looks.

    | Setting | Default | Notes |
    | --- | --- | --- |
    | **Theme** | System | System, Light or Dark. |
    | **Interface size** | Medium | Small, Medium, Large or XL. Scales text, spacing and controls in every window. |
    | **Log text size** | 14 px | 12–48 px; the same setting as **Text size** in Log & Sessions. |
    | **Switch to mini mode when games go full screen** | Off | When the game goes full screen on Kimochi's screen: on, Kimochi shrinks to [Mini mode](/reading/mini-mode/#when-the-game-goes-full-screen); off, it keeps its size and stays on top of the game. |
    | **Sound effects** | On | Every sound on or off. The speaker in each title bar toggles them too. |
    | **Scan sounds** | On | Under Sound effects: a sound when a scan starts, adds lines to the Log or fails. |
    | **Click sounds** | On | Under Sound effects: a click for buttons, switches and menus, and a whoosh when the sidebar shows or hides. |
    | **Volume** | 50% | Under Sound effects: how loud every sound effect plays. |
    | **Debug overlay** | Off | Marks the scanned text boxes over the source and opens the Diagnostics window. |
    | **Kimochi in Steam** | — | Linux with Steam only. See [Steam Deck](/install/steam-deck/#adding-to-steam-later). |
    | **Welcome guide** | — | **Open** runs the [welcome guide](/welcome-guide/) again. |
    | **Overlay hints** | Showing | **Show again** brings back the overlay's [hint bar](/reading/overlay/#the-hint-bar) after you closed it. |

  <TabItem label="Language">

    | Setting | Default | Notes |
    | --- | --- | --- |
    | **Language** | Japanese | One of [49 languages](/language/support/#languages); every one but Japanese is experimental. Part of your account's preferences, so it syncs. |

    computer that read it, and, with Yomitan, the account's Yomitan profile.

  <TabItem label="Log & Sessions">
    How the transcript reads, which lines it keeps, and your sessions. See [The Log](/log/the-log/)
    and [Sessions](/log/sessions/).

    | Setting | Default | Notes |
    | --- | --- | --- |
    | **Text size** | 14 px | 12–48 px; also A− and A+ in the Log's footer. |
    | **Read-aloud voice** / **Voice model** | Eleven v3 | With Kimochi Cloud, in Japanese. |
    | **Drop lines** | No Japanese | Or **Mostly not Japanese**, or **Off**, named for the language you're learning. Applies to the overlay too. |
    | **Skip repeats** | 1 | Drop a line that matches any of the last N lines (1–20). |
    | **Merge streamed lines** | Off | Characters to compare: 4. |
    | **Keep at most** | 5000 | Lines per session. |
    | **Text replacements** | None | Pattern rules applied to incoming lines. |
    | **Pause when idle for** | 60 s | The reading timer (10–600 s). |
    | **Sessions** | — | Every session: drag to reorder, click a name to rename, switch, delete, or add one. |
  </TabItem>

  <TabItem label="Anki">
    Cards through AnkiConnect. See [Anki](/lookups/anki/).

    | Setting | Default |
    | --- | --- |

    | ↳ **API key** | Empty; not synced |
    | **Mining** tab: **Open … Anki settings** (Yomitan, Hachidori) | The engine's Anki settings, AnkiConnect address and key included |
    | ↳ **Enable Mining** / **Deck** / **Note type** (Yomitan API) | Off / — / — |
    | ↳ **Detect from Anki** / **Import from Yomitan** / **Field mapping** (Yomitan API) | — |
    | **Card enhancement** tab: **Enhance with sentence audio** | Off (turning it on in Japanese downloads the speech model) |
    | ↳ **Audio field** | `SentenceAudio`, found in Anki when turned on |
    | ↳ **Advanced**: **Start offset** / **End offset** / **Seconds kept** / **Clips kept** | 0 ms / 0 ms / 30 / 15 |
    | **Card enhancement** tab: **Enhance with screenshot** | On |
    | ↳ **Picture field** | `Picture`, found in Anki when turned on |
    | ↳ **Screenshots kept** | 50 |
    | **Card enhancement** tab: **Add tags** / **Tags** | On / `kimochi, {{session-name}}` |

    10ten adds no cards, and an engine that isn't downloaded yet only offers **Go to Dictionary**.

  <TabItem label="Shortcuts & Controls">
    Keyboard shortcuts and a game controller. See [Keyboard shortcuts](/reference/shortcuts/) and
    [Controller](/controller/).

    | Setting | Default |
    | --- | --- |
    | **Scan** | <kbd>⇧⌘8</kbd> / <kbd>Shift+F8</kbd>, no gamepad button |
    | **Controller menu** | <kbd>⇧⌘Space</kbd> / <kbd>Shift+F9</kbd>, LS + RS (R4 on a Steam Deck) |
    | **Lookup key** | Shift (only with **Click through text to the game** on; not on Linux with Wayland) |

    | **Scan after a button press**: **Button** / **Delay** | None (off) / 500 ms |
    | **Controller menu**: **Select** / **Back** | A / B |
    | **Reading**: **Word or character** / **Play audio** / **Previous definition** / **Next definition** / **Show all controls** | Y / X / LB / RB / View |
    | **Connected gamepads** / **Button test** | — |

    Scan and Controller menu can also be a middle,
    back or forward mouse button; see [Mouse buttons](/reference/shortcuts/#mouse-buttons).
  </TabItem>
