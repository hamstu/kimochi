---
title: Keyboard shortcuts
description: Every keyboard shortcut in Kimochi, global and in-window.
---

On macOS <kbd>⌘</kbd> is Command and <kbd>⇧</kbd> is Shift. In Kimochi's own windows, use
<kbd>Ctrl</kbd> on Windows and Linux where a Mac uses <kbd>⌘</kbd>.

## Global shortcuts

These work while another app (your source) is in front. Change them, give them a gamepad button, or
turn them off in **Settings → Shortcuts & Controls → Shortcuts**.

| Shortcut | macOS | Windows and Linux | What it does |
| --- | --- | --- | --- |
| **Scan** | <kbd>⇧⌘8</kbd> | <kbd>Shift+F8</kbd> | Scans the current source. In Quick Shot, asks you to draw an area first; pressed again, scans the area you drew (or closes Quick Shot if you haven't drawn one). |
| **Controller menu** | <kbd>⇧⌘Space</kbd> | <kbd>Shift+F9</kbd> | Opens the radial menu over the game (gamepad: LS + RS; R4 on a Steam Deck). |

Windows and Linux use F-keys by default because many visual novels skip text while
<kbd>Ctrl</kbd> is held. If you set your own shortcuts before this default changed, they're kept.

To change one, click it, press the new keys (<kbd>Esc</kbd> cancels, <kbd>Backspace</kbd> clears).
A shortcut needs <kbd>⌘</kbd> / <kbd>Ctrl</kbd> or <kbd>Alt</kbd>, unless its key works on its own:
an F-key, <kbd>Insert</kbd>, or on Windows and Linux <kbd>Pause</kbd> or <kbd>Scroll Lock</kbd>
(each also with <kbd>Shift</kbd>).

### Mouse buttons

The Scan and Controller menu shortcuts can also be the **middle**, **back** or **forward** mouse
button: click the shortcut, then press the button. A bound button goes to Kimochi only, not to the
game or the app underneath; buttons you haven't bound work as before.

- **Windows:** works as is.
- **macOS:** needs Kimochi to be allowed under **Accessibility**
  (**Settings → Sources → macOS permissions**, or [Install on macOS](/install/macos/)).
- **Linux:** not supported yet.

## Log

| Keys | What they do |
| --- | --- |
| <kbd>Shift</kbd> + hover | Look up the word under the pointer |
| <kbd>R</kbd> (hovering a line) | Read aloud (with a Kimochi account) |
| <kbd>C</kbd> (hovering a line) | Copy the line (the English, when translated) |
| <kbd>T</kbd> (hovering a line) | Translate / show original |
| <kbd>E</kbd> (hovering a line) | Explain |
| <kbd>D</kbd> (hovering a line) | Delete the line |
| <kbd>⌘C</kbd> / <kbd>Ctrl+C</kbd> | Copy the selection |

A line's **⋯** menu (or a right-click on it) shows the same letters, and pressing one while the
menu is open chooses it. The same goes for the Notebook and the Anki tab.

## Notebook

| Keys | What they do |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>Home</kbd> <kbd>End</kbd> | Move through the list |
| <kbd>Return</kbd> | Edit the entry |
| <kbd>/</kbd> | Search |
| <kbd>Esc</kbd> | Close the editor, or clear the search |
| <kbd>E</kbd> (hovering an entry) | Edit it |
| <kbd>C</kbd> (hovering an entry) | Copy its name |
| <kbd>D</kbd> (hovering an entry) | Delete it (asks first) |

## Anki tab

| Keys | What they do |
| --- | --- |
| <kbd>O</kbd> (hovering a card) | Open it in Anki |
| <kbd>D</kbd> (hovering a card) | Delete it (asks first) |

## Crop and Quick Shot area

The same keys work in the OCR crop area (blue), the Anki crop area (green) and Quick Shot.

| Keys | What they do |
| --- | --- |
| Drag | Draw the area |
| <kbd>Space</kbd> (held, while drawing) | Move the area |
| Arrows / <kbd>Shift</kbd> + arrows | Nudge by 1 / 10 points |
| <kbd>Return</kbd> or double-click | Confirm |
| <kbd>Esc</kbd> | Cancel |

## Controller menu and word-by-word reading

| Keys | What they do |
| --- | --- |
| Arrows | Move between items; in reading, previous/next word (◀ ▶) and line (▲ ▼); in the pop-up, choose a button |
| <kbd>Return</kbd> | Choose; in reading, into the pop-up (or look the word up again); in the pop-up, press the chosen button |
| <kbd>Space</kbd> | In reading, step by word or by character |
| <kbd>Esc</kbd> | Close, back to your source; from the pop-up, back to the text |

In the full-screen dictionary, <kbd>←</kbd> <kbd>→</kbd> move word to word, <kbd>↑</kbd>
<kbd>↓</kbd> scroll, <kbd>Return</kbd> adds the entry to Anki (Yomitan API) or moves into the
pop-up, and <kbd>Esc</kbd> goes back to your source.
