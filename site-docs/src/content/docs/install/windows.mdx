Kimochi runs on **Windows 10 22H2 or Windows 11**, on **x64** or **ARM64**.

<Steps>

1. Download the installer for your PC from [kimochiapp.com](https://kimochiapp.com/#download):
   `Kimochi_<version>_x64-setup.exe` for most PCs, `Kimochi_<version>_arm64-setup.exe` for ARM.

2. Run it. It installs Kimochi for your user account (no administrator needed), in English or
   Japanese, and fetches Microsoft's WebView2 runtime if your PC doesn't have it yet.

3. Open Kimochi and follow the [welcome guide](/welcome-guide/).

</Steps>

Windows builds are signed, so Windows opens them without
a warning. Updates install from inside the app and relaunch it.

## OneOCR, the Windows OCR engine

Windows has an on-device OCR engine of its own, in the Snipping Tool, and Kimochi can use it:
choose **OneOCR** in **Settings → OCR**. See [OCR engines](/reading/ocr-engines/#oneocr).

- **Windows 11:** install or update **Microsoft Snipping Tool** from the Microsoft Store.
- **Windows 10:** Snipping Tool doesn't include it, so OneOCR needs three files from a recent
  Windows 11 Snipping Tool package: `oneocr.dll`, `oneocr.onemodel` and `onnxruntime.dll`. Put a
  matching x64 or ARM64 set in your user folder under `.config\oneocr`. The
  [OneOCR setup instructions](https://github.com/AuroraWright/oneocr#readme) explain where to find them.

## Text hooking

On Windows, Kimochi can read a game's text from inside the game instead of with OCR: choose
**Change source → Window or screen**, pick the game, and turn on **Text hooking** under its card.
The hooker (LunaHook, about 6 MB) downloads the first time. See [Text hooking](/reading/text-hooker/).

## Uninstalling

Uninstall Kimochi from **Settings → Apps → Installed apps** like any other app. The uninstaller's
first page has a box, **Also remove my Kimochi settings and data**, which starts unticked:

- **Left unticked**, your settings, Log, sessions, dictionaries and downloaded engines stay on your
  PC, and installing Kimochi again picks up where you left off.
- **Ticked**, Kimochi removes them too, so the next install starts fresh with the welcome guide. It
  deletes:

  | What | Where |
  | --- | --- |
  | Settings, the Log, sessions, stats and the Notebook | `%APPDATA%\dev.kimochi.app` |
  | Downloaded engines and models, imported dictionaries, screenshots, text hooking files, logs and the `kimochi` command | `%LOCALAPPDATA%\dev.kimochi.app` |
  | Sentence audio captures | `%LOCALAPPDATA%\kimochi-voicehook` |

  It also takes the `kimochi` command off your PATH and unregisters the
  [Yomitan API](/lookups/dictionaries/#yomitan-api) helper if Kimochi installed it for your
  browsers. You are signed out on this PC; what Kimochi Cloud synced stays in your account (see
  [Managing your account](/cloud/#managing-your-account)).

Close any game Kimochi was reading first: a file a running game still has open is left behind.
Updates never remove anything, and neither does a silent uninstall (`uninstall.exe /S`). To remove
the data after uninstalling with the box unticked, quit Kimochi and delete the folders in the
table (paste each path into File Explorer's address bar).
