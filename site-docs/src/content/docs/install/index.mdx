the right file for your computer; **Other platforms** lists every build. Builds are also published on
[GitHub Releases](https://github.com/hamstu/kimochi/releases).

## Updates

Kimochi updates itself. In release builds it checks shortly after launch and then every six
hours, and shows a notice in the sidebar when a new version is out. You start the download and you
choose when to restart. You can also check from
**Settings → About → Updates**.

<Screenshot id="update-notice" alt="The sidebar's update notice: Kimochi 0.2.0 is available, with a Download button." width={272} />

<Screenshot id="settings-updates" alt="Settings, About, Updates: the current version, What's new and a Download button for the new version." width={760} />

After an update, **What's new** shows the release notes.

Every update is checked against Kimochi's signing key before it is installed. Pre-releases and
development builds are never offered as updates.

## Building from source

Kimochi is open source under the GPL-3.0. To build it yourself, see the
[README](https://github.com/hamstu/kimochi#building-from-source).
