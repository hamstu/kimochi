## Which file is which

| Platform | File | Notes |
| --- | --- | --- |
| macOS, Apple silicon | `Kimochi_<version>_aarch64.app.zip` | Signed and notarised. |
| Windows x64 | `Kimochi_<version>_x64-setup.exe` | Installs for the current user. |
| Windows ARM64 | `Kimochi_<version>_arm64-setup.exe` | |
| Linux x64 | `kimochi_<version>_amd64.AppImage` or `.deb` | The one-line installer uses the AppImage. |
| Linux ARM64 | `kimochi_<version>_aarch64.AppImage` or `kimochi_<version>_arm64.deb` | |

Nightly builds drop the `_<version>` part of the name.

## Updates

Kimochi updates itself. In release builds it checks quietly shortly after launch and then every six
hours, and shows a notice in the sidebar when a new version is out. You start the download and you
choose when to restart; nothing is installed behind your back. You can also check from
**Settings → General → Updates**.

<Screenshot id="settings-updates" alt="Settings, General, Updates: the current version, What's new and a Download button for the new version." width={760} />

After an update, **What's new** opens once on its own with the release notes. It is always in
**Settings → General → Updates → What's new**.

Every update is checked against Kimochi's signing key before it is installed. Development (nightly)
builds are never offered as updates.
